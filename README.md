## What is this?

This guide serves as a front-end for actually figuring out what this is (which is the driver, mind), how to install it, and common pitfalls you may find yourself falling into. Do note this driver is a WIP, and is constantly shifting because of advancements with log files. [Should I use this driver?](/is-it-for-me.md)

This guide specifically focuses on:

- Installing macOS using the 1401 app or your own EFI made using the original [Dortania OpenCore guide](https://dortania.github.io/) 
- Guiding you through installing the driver, and using macOS with said driver
- Troubleshooting and problems

Because this driver is so new, temperamental, and awesome, you will be required to read this guide. Please. Do not just go straight to AI.
